# ChatGPT

ChatGPT is an AI assistant that can help with writing, learning, brainstorming,
coding, summarizing information, and solving everyday problems through natural
language conversation.

## What ChatGPT Can Do

- Answer questions and explain concepts in plain language
- Draft, revise, and summarize text
- Help write, debug, and understand code
- Generate ideas for projects, plans, and creative work
- Assist with research by organizing information and suggesting next steps

## Good Ways to Use ChatGPT

ChatGPT works best when prompts include clear goals, relevant context, and any
constraints that matter. For example, instead of asking for "a summary," specify
the audience, desired length, and the most important points to include.

## Responsible Use

ChatGPT can make mistakes, so important answers should be reviewed and verified
against reliable sources. Avoid sharing private, sensitive, or confidential
information unless you are using an environment specifically approved for that
data.

## Getting Started

1. Ask a clear question or describe the task.
2. Provide examples, context, or requirements.
3. Review the response and ask follow-up questions.
4. Verify critical facts before relying on the answer.

Used thoughtfully, ChatGPT can be a practical partner for learning, creating, and problem solving.
